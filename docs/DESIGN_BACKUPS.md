# Vishnu Tours Design Backups

The public website designs are preserved in Git so they can be restored without
changing booking, payment, dashboard or database code.

## Restore Points

- `design-previous-mobile-2026-08-22`: previous mobile-polished design.
- `design-current-pre-stitch-2026-08-22`: design active immediately before the
  Executive Premiere redesign.
- `backup/pre-stitch-redesign-2026-08-22`: GitHub backup branch for the complete
  pre-redesign application.

## Restore Method

Restore public design files from a tag into a new working branch. Do not reset
the production branch or replace API, database, Razorpay, booking, email or
portal workflow files when only a visual rollback is requested.
